About Me and This Project

Hello! My name is Phú, and I am from Vietnam. This website was created as the Final Project for the Introduction to CSS3 course in the Web Design for Everybody Specialization.

Through this project, I have practiced applying fundamental CSS concepts including the CSS box model, positioning, accessible navigation, CSS Grid, and CSS Flexbox. Each page demonstrates different styling methods and responsive layouts.
