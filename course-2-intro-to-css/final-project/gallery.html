This is an example of CSS Grid

Welcome to my photo gallery! This page displays my favorite personal snapshots arranged using a two-column CSS Grid layout (grid-template-columns: repeat(2, 1fr)). All images are styled using the CSS Box Model (with custom border, padding, and border-radius) and feature an interactive hover transition.

Exploring wildlife and nature at the zoo with friends

Grid Layout Highlights

  • Two Equal Columns: Configured via grid-template-columns: repeat(2, 1fr).
  • Consistent Gap: Clean 24px spacing between all grid cards.
  • Responsive: On smaller mobile screens, the grid smoothly collapses into a single column.
  • Interactive Hover: Hovering over any image initiates a gentle scale zoom with shadow depth.
