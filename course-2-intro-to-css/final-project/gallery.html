CSS Grid Gallery

Two-Column CSS Grid Layout

This photo gallery demonstrates a two-column CSS Grid layout configured using display: grid and grid-template-columns: repeat(2, 1fr). Additional grid properties such as gap: 24px, justify-items: center, and align-items: stretch are applied to the parent container.

Every image is styled using the CSS Box Model with custom border, padding, and border-radius properties. When you hover over any image, an interactive transition smoothly scales the image and enhances its shadow depth.

Grid Features Applied

  • Two-Column Layout: Multiple columns created via grid-template-columns: repeat(2, 1fr).
  • Additional Properties: Uses gap: 24px, row-gap: 24px, column-gap: 24px, justify-items: center, and align-items: stretch.
  • Box Model Styling: All images use border: 5px solid #1e3a8a, padding: 8px, and border-radius: 16px.
  • Hover Transition: Images elevate and rotate subtly using transform: scale(1.06) rotate(1.5deg) on hover.
