This is an example of CSS Flex

In my free time, I love balancing quiet moments like sipping iced coffee or playing with cats with outdoor activities and trips with friends. This page utilizes CSS Flexbox (display: flex, flex-wrap: wrap, and justify-content: space-around) for flexible card alignment.

Notice how every image alternates its corner styling using the :nth-child pseudo-class! Even-numbered cards feature smooth top-left/bottom-right leaf curves with a green border, while odd-numbered cards feature inverted curves with an orange accent border.

Hobby 3: Weekend Walks — Exploring nature parks and visiting the city zoo.

Hobby 4: Community Events — Engaging in campus festivals and outdoor sports.

CSS Techniques Demonstrated

  • Flexbox Distribution: Cards flex responsively across rows via display: flex and flex-wrap: wrap.
  • Advanced :nth-child Selectors: :nth-child(even) and :nth-child(odd) give each consecutive image an artistic, alternating leaf-shaped border-radius and unique border color.
  • Box Model: Every image applies border, padding, and custom border-radius.
  • Interactive Transitions: Smooth zoom and shadow expansion on :hover.
